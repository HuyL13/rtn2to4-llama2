# Reference training recipe

These files are unmodified copies from
https://github.com/huynguyenquang-collab/phaseA_fingerprint at commit a61c314.
They document the source of the paged AdamW and CTCC batch/precision settings.
The rtn2to4 pipeline does not execute these reference shell scripts. Its local
implementation avoids their Perinucleus response-file error, unrestricted
environment setup, latest-branch clones and checkpoint cleanup behavior.

See ../../docs/phasea-training-integration.md for the adapted runnable pipeline.
